Hash Generator

Generate cryptographic checksums of text or files using SHA-1, SHA-256, SHA-384 or SHA-512. Useful for verifying downloads, checksums and data integrity. MD5 is not available in browsers’ secure crypto — use SHA-256 instead.

Your files never leave your device — everything runs in your browser.

MD5 is not available in browsers’ secure crypto — use SHA-256 instead.

How to use

  1. Type text or choose a file to hash.
  2. Pick the algorithm: SHA-256 is the best default.
  3. Click Generate hash and wait a moment for large files.
  4. Copy the hex digest with one click.

Frequently asked questions

Why is there no MD5 option?

MD5 is not available in browsers’ secure crypto (WebCrypto) — use SHA-256 instead. MD5 is also considered broken for security purposes, so SHA-256 is the safer choice anyway.

Which algorithm should I choose?

SHA-256 is the best default: widely supported and secure. SHA-512 is stronger but produces a longer digest; SHA-1 is only suitable for non-security checks like deduplication.

Can a hash be reversed to get the original text?

No. Cryptographic hashes are one-way — you cannot recover the input from the digest. That is what makes them useful for integrity checks and password storage (with a proper salt and KDF).

How do I verify a downloaded file’s checksum?

Choose the file, select the same algorithm the publisher used (usually SHA-256), generate the hash, and compare it character-for-character with the published checksum. If they match, the file is intact.

Is my file uploaded to a server?

No. The file is read and hashed locally in your browser — it never leaves your device.
