Case Converter

A case converter that changes the capitalization of any text in one click — UPPER CASE, lower case, Title Case, Sentence case, camelCase, PascalCase, snake_case, kebab-case, aLtErNaTiNg and InVeRsE.

Conversion happens live as you type, and line breaks and spacing are preserved — only letter casing changes. Handy for headlines, code identifiers and cleaning up pasted text.

Frequently asked questions

What is the difference between camelCase and PascalCase?

Both join words without spaces and capitalize each word after the first. camelCase starts lowercase (myVariable) while PascalCase capitalizes the first word too (MyVariable).

How does Sentence case work?

The whole text is lowercased first, then the first letter of each sentence is capitalized. Proper nouns are not preserved, so check names afterwards.

What is aLtErNaTiNg case used for?

Mostly playful or meme-style text. It alternates lowercase and uppercase letters while leaving numbers, spaces and punctuation untouched.

Does the tool change my line breaks?

No. Conversion preserves line breaks and spacing; only letter casing changes.
