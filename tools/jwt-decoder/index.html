JWT Decoder

Paste a JSON Web Token to inspect its header and payload as formatted JSON. If the payload contains standard iat (issued at) or exp (expires) claims, they are shown as human-readable dates.

Your files never leave your device — everything runs in your browser.

Signature is NOT verified — never trust a token based on this. Verify signatures on your own server.

How to use

  1. Paste your JWT (header.payload.signature) into the text area.
  2. Click Decode JWT.
  3. Read the header and payload as formatted JSON.
  4. Check the issued-at and expiry dates if the token carries them.

Frequently asked questions

Does this tool verify the token signature?

No. Signature is NOT verified — never trust a token based on this output. Always verify signatures on your own server with the correct secret or public key.

Is it safe to paste my token here?

Decoding runs entirely in your browser, so the token is never uploaded. Still, avoid pasting production tokens with sensitive claims into any website as a habit.

What are the iat and exp claims?

iat (issued at) and exp (expiration time) are Unix timestamps in the payload. This decoder converts them to readable dates and flags expired tokens.

Why does decoding fail?

The token must have three dot-separated Base64url segments (header.payload.signature) with valid JSON in the first two. Truncated or URL-mangled tokens fail with an error.
