Password Generator

A password generator that creates strong, random passwords using your browser’s cryptographic random number generator. Set the length from 8 to 64 characters and mix lowercase, uppercase, digits and symbols to taste.

Every password comes with an entropy rating so you can see at a glance how resistant it is to guessing. Generate as many as you like — nothing is stored or transmitted.

Your files never leave your device — everything runs in your browser.

Character sets

How to use

  1. Drag the slider to set the password length (8–64 characters).
  2. Tick the character sets you want to include: lowercase, uppercase, digits, symbols.
  3. Optionally exclude ambiguous characters that are easy to mix up.
  4. Click "Generate new password" (or it regenerates automatically) and copy the result.

Frequently asked questions

How random are these passwords?

They are generated with your browser’s cryptographic random number generator (crypto.getRandomValues) — the same source of randomness browsers use for security features.

What does the entropy number mean?

Entropy, measured in bits, estimates how hard the password is to guess by brute force. Around 80 bits or more is considered strong for most purposes.

Should I exclude ambiguous characters?

Characters like l, I, 1, O and 0 look alike in some fonts and cause mistakes when a password must be read or typed by hand. Excluding them helps in those cases.

Is my password sent anywhere?

No. Generation happens entirely on your device and nothing is stored or transmitted.
