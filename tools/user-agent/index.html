Frequently asked questions

What is a user agent string?

It is a line of text your browser sends to every website, identifying the browser version, operating system, and device. Sites use it to serve the right layout or troubleshoot issues.

Can a user agent be faked?

Yes — browsers and extensions can override it, so it is an identification hint, not proof. The details here reflect what your browser reports, which may differ from the real device if spoofing is enabled.

Is my user agent private information?

It is sent to every site you visit, so it is not secret — but combined with other signals it can help trackers fingerprint a device. Treat it as semi-public.

Why does it mention "Mozilla" even in Chrome?

For historical compatibility, nearly all browsers start their user agent with "Mozilla/5.0". It is a legacy quirk, not a sign you are using Firefox.
