Internet Speed Test

Run a quick speed test: we measure round-trip ping and jitter to this site and to our CDN, then download a real file to estimate your download throughput. Results appear in seconds.

This is a browser-based estimate of your connection to our CDN (jsDelivr), not a lab-grade test — other servers may be faster or slower.

Browser-based estimate of your connection to our CDN (jsDelivr). Not a lab-grade test. Upload speed is not measured — there is no server to upload to.

How to use

  1. Close heavy downloads or streams for a cleaner result.
  2. Click "Start test".
  3. Wait for the ping, jitter, and download phases to finish.
  4. Compare runs: repeat the test to spot variability on your connection.

Frequently asked questions

What does this speed test measure?

Ping (median round-trip latency over 10 samples), jitter (average variation between consecutive samples), and download throughput measured by fetching a real CDN file three times and taking the median.

Why is there no upload speed test?

Upload speed requires a server to receive the data, and this site has no backend — everything runs in your browser. The test honestly reports download and latency only.

Why is my download speed lower than my plan advertises?

Browser-based tests add overhead from encryption, the JavaScript runtime, and shared network paths. It is an estimate of real-world CDN throughput, not a lab measurement. Wi-Fi and other devices on the network also affect it.

Should I trust a single result?

Run the test two or three times and compare. Speed varies with network congestion, time of day, and what else is using your connection.

Does the test use my data allowance?

Yes, a little: the download phase fetches a library file three times. Each run uses only a few megabytes.
