# QuickTools — 59 Free Online Tools

A static, 100% client-side all-in-one free online tools website. Every tool runs
entirely in the visitor's browser — no uploads, no sign-up, no server needed.

## Categories (59 tools)
PDF tools, Calculators, Image tools, File converters, Internet tools,
QR & generators, Text tools, Video/Audio tools, Unit converters, Developer tools.

## Deploy
This repo is deploy-ready for **Firebase Hosting** (`firebase.json` included)
or **GitHub Pages** (serves from repo root).

Built with a Node.js static site generator (`site/build.mjs`).
